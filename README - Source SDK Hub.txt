SOURCE MODEL KIT - рабочая оболочка для утилит Source SDK и работы с моделями
=======================================================

Что это
-------
Одно окно, в котором есть всё для работы: Crowbar, VMT Editor, VTF Version
Changer, BSPSrc и встроенный проводник файлов. Окно делится на области, как в
Blender, поэтому можно держать на экране проводник, пару утилит и главную
одновременно и не переключаться между десятками окон. Оригинальные программы
не изменены: оболочка запускает их как обычные процессы и встраивает их окна.

Язык интерфейса / Interface language
------------------------------------
- Справа в строке состояния переключатель RUS / ENG. После выбора оболочка предложит перезапуск и
  откроется на выбранном языке (раскладка областей сохраняется). Язык хранится в SourceSDK.settings.ini (lang=ru|en).
- При первом запуске язык выбирается по языку Windows (русский - RUS, остальные - ENG).
- Click RUS / ENG at the right of the status bar to switch the interface language; the shell restarts
  and keeps your layout. The language is stored in SourceSDK.settings.ini (lang=ru|en). On the first start it
  follows the Windows UI language.
- Новые тексты интерфейса: русская строка в коде оборачивается в Loc.T("..."), а английский вариант
  добавляется в словарь Shell\Loc.cs.

Как получить SourceSDK.exe (один раз)
-------------------------------------
1. Папка Shell должна лежать рядом с Crowbar.exe.
2. Запустите Shell\build.bat - он соберёт SourceSDK.exe встроенным в Windows
   компилятором (.NET Framework 4.x, есть в Windows 10/11, ничего ставить не нужно).
   Если оболочка в этот момент запущена - сначала закройте её.
3. В корне SDK появится SourceSDK.exe. Дальше запускайте только его.

Для BSPSrc нужна установленная Java (JRE 8+).

Полный экран и второй монитор
-----------------------------
F11               - полный экран на текущем мониторе (повторно - выход)
Ctrl+F11          - перенести окно на следующий монитор
кнопки справа вверху - то же самое мышью
"SourceSDK - второй монитор.bat" - запуск сразу на весь экран на мониторе №2
                    (номер меняется в параметре --screen=N, ключ --fullscreen)
Положение окна, монитор, полноэкранный режим и раскладка областей запоминаются
(файл SourceSDK.settings.ini рядом с exe).

Области (как в Blender)
-----------------------
- Окно состоит из областей; в каждой - свои вкладки (Главная, Проводник, программы).
- Разделить область:
    * потяните за УГОЛОК заголовка области (две косые черты слева или справа
      вверху): влево/вправо - вертикальный разрез, вниз - горизонтальный.
      Отпустите мышь над областью - разрез сделан, вне области - отмена;
    * или Ctrl+\ (вертикально) / Ctrl+Shift+\ (горизонтально);
    * или меню "..." в заголовке области, или кнопка "Окна" сверху.
- Размер: тяните линию между областями; двойной клик по линии - пополам.
- Ctrl+Пробел - развернуть область под курсором на всё окно / вернуть
  (двойной клик по пустому месту заголовка - то же самое).
- Вкладки можно перетаскивать между областями и менять местами.
- ПКМ по вкладке: вынести в новую область справа/снизу, перезапустить,
  открепить в отдельное окно, закрыть, завершить принудительно.
- Ctrl+W - закрыть вкладку, Ctrl+Shift+W - закрыть область,
  Ctrl+T - новая вкладка проводника, Ctrl+Tab / Ctrl+1..9 - переключение вкладок.
- F11, Ctrl+F11, Ctrl+Пробел и Ctrl+\ работают даже тогда, когда фокус внутри
  встроенной программы; остальные сочетания - когда фокус в оболочке.
- Область, где вы кликнули последний раз, считается активной (подсвечена):
  в неё открываются новые вкладки с верхней панели.

Проводник
---------
- Дерево папок слева (скрывается в узкой области), список справа, фильтр по имени.
- Двойной клик/Enter - открыть; Backspace или Alt+Вверх - на уровень выше;
  Alt+Влево/Вправо или кнопки мыши "назад/вперёд" - история.
- Ctrl+C / Ctrl+X / Ctrl+V - копировать, вырезать, вставить (совместимо с
  буфером Windows); перетаскивание мышью: перенос, с Ctrl - копия, в дерево и в папки.
- F2 - переименовать, Delete - в корзину, Shift+Delete - удалить навсегда (с вопросом).
- Ctrl+Shift+N - новая папка, F5 - обновить (список обновляется и сам),
  Ctrl+L - адресная строка, Ctrl+F - фильтр. Средняя кнопка по папке - в новой вкладке.
- ПКМ по файлу: "Открыть в инструменте" передаёт файл программе как аргумент
  командной строки (работает, если сама программа это поддерживает).
- Значок "глаз" - показать скрытые и системные файлы.

Инструменты
-----------
- Карточки на "Главной", кнопки сверху и кнопка "+" во вкладке открывают инструменты.
  Повторный запуск уже открытого инструмента просто переключает на его вкладку.
- "+ Добавить инструмент" - любые свои exe/jar/bat (хранятся в SourceSDK.tools.ini
  рядом с SourceSDK.exe; на карточке пользовательского инструмента ПКМ -> удалить).
- Если окно программы не встраивается нормально - ПКМ по вкладке -> "Открепить",
  а для своих инструментов можно снять галочку "Встраивать в оболочку".

Темы оформления
---------------
Кнопка с палитрой справа вверху: Тёмная, Светлая (серая, как GitHub),
Оригинальная (хаки, как старый браузер серверов Valve). Переключается на лету,
выбор запоминается.

Закреплённые папки
------------------
- Звезда в панели проводника: список закреплённых папок, закрепить/открепить текущую.
- ПКМ по папке (в списке или в дереве) -> "Закрепить в быстром доступе".
- Закреплённые папки показываются первыми в дереве проводника и общие для всех проводников.

Этапы работы (как рабочие пространства в Blender)
-------------------------------------------------
- Вкладки вверху ("Обзор", "Модели", "Текстуры"...) - готовые раскладки областей
  вместе с нужными программами. Ctrl+Alt+1...9 - переключение с клавиатуры.
- Этап запоминает свою раскладку сам: изменили области - при переходе на другой этап
  и при выходе они сохранятся. Уже запущенные программы при смене этапа не закрываются.
- "+" - новый этап из текущей раскладки; двойной клик - переименовать;
  ПКМ - дублировать, сбросить к исходному, удалить.
- Программы без встраивания (VS Code, Photoshop) на этапе показываются вкладкой с кнопкой
  "Запустить" и не стартуют сами. VS Code и Photoshop при первом запуске добавляются
  автоматически, если найдены (SourceSDK.tools.ini); остальное - через "Добавить инструмент".
- Файл этапов: SourceSDK.workspaces.ini (можно копировать на другой компьютер).
Проводник: дерево и закреплённые папки
--------------------------------------
- Дерево папок слева есть в каждом проводнике, пока область шире ~300 px.
- Под деревом - зона "Закреплённые": клик открывает папку, средняя кнопка - в новой вкладке,
  ПКМ - открепить. Закрепить: звезда в панели, ПКМ по папке, или перетащить папку в эту зону.

VS Code внутри оболочки
-----------------------
VS Code открывается как "закреплённое окно": это настоящее окно редактора без рамки, привязанное к
области (двигается, скрывается и сворачивается вместе с ней). Так ввод и переключение раскладки работают
как в обычном VS Code. Запускается отдельным экземпляром со своей папкой данных
(%APPDATA%\SourceSDKHub\vscode, настройки и сочетания клавиш копируются из вашего VS Code один раз).
Для других Electron-программ в SourceSDK.tools.ini добавьте строку Overlay=1.

Уведомления
-----------
Колокольчик справа вверху: журнал событий (копирование, удаление, обновление текстур, закрытие программ)
и переключатель всплывающих окон. Всплывающие уведомления показываются поверх любых встроенных программ.

Просмотр моделей (.mdl)
-----------------------
- Открыть: ПКМ по .mdl в проводнике -> "Просмотреть модель в оболочке", кнопка "Просмотр модели" на Главной,
  "+" в заголовке области, перетаскивание файла в окно просмотра или SourceSDK.exe model.mdl [--seq=имя_секвенции].
- Нужны рядом .vvd и .dx90.vtx (так компилирует Crowbar/studiomdl). Версии MDL 44-49.
- Текстуры берутся из папки materials выше по дереву от модели; остальное - через "Привязки" (см. ниже).
- Мышь: ЛКМ - вращение, ПКМ/СКМ - сдвиг, колесо - масштаб, двойной клик или F - вписать, G - сетка, W - каркас,
  Shift+ЛКМ - повернуть источник света. Бодигруппы и скины - в панели справа; режимы света: сцена, фонарь, fullbright, без текстур.
- Автообновление: при сохранении .vtf/.vmt текстура обновляется на модели сама, при перекомпиляции .mdl/.vvd/.vtx модель
  перезагружается с теми же бодигруппами, скином и выбранной анимацией.

Анимации
--------
- Панель внизу: выбор секвенции (поиск по имени, список из самой модели и подключённых файлов), пуск/пауза (Пробел),
  покадровая прокрутка (стрелки), ползунок, скорость 0.1x-4x, зацикливание.
- Секвенции с блендами (walk, run, aim...) имеют ползунки поз-параметров (move_yaw, aim_pitch ...) в панели справа.
- Поддержаны: сжатые анимации, длинные анимации по секциям, бленды 1D/2D, аддитивные анимации, .
- Не поддержаны: внешние .ani-блоки (секвенция помечается "нет данных"), IK, процедурные кости, лицевая анимация.

Скелет, хитбоксы, физика
------------------------
- Раздел "Показать": скелет, хитбоксы (раскрашены по группе попадания), физика (.phy). Всё следует за анимацией.
- Наведите мышь на кость, хитбокс или физическое тело - подсветка и подсказка (имя, группа, кость, размеры).

Слои: наложение одной анимации на другую
-----------------------------------------
- Правая панель, раздел "Слои анимаций" (или ПКМ по полю секвенции внизу): "Добавить слой..." накладывает
  секвенцию поверх основной. Для слоя: вес, какие кости (по weightlist секвенции / все / выбранная кость
  и все её потомки), режим (авто / смешать / добавить минус кадр 0) и "фаза как у основной".
- Скелет раскрашивается: оранжевые - кости слоя, которые отличаются от основной анимации; жёлтые - слой
  на них есть, но совпадает; серые - слой их не затрагивает. В подсказке кости - вес слоя на ней.
- В разделе "Анимация" для выбранной секвенции показано, что записано в её weightlist (если там одни
  единицы - анимация полноценная, на все кости, и ничего не накладывает).
- "Скопировать weightlist для QC" / "Скопировать пример $sequence" кладут в буфер готовый текст для QC.
- Чтобы анимация накладывалась в самой игре, в QC нужны $weightlist с нулями на костях, которые менять
  не надо, и weightlist "имя" в $sequence (плюс fadein/fadeout; для аддитивных - delta).

Привязки и зависимости
----------------------
Кнопка "Настроить привязки..." в панели справа:
- папки с материалами (если часть материалов лежит не рядом с моделью - игра, библиотека, проект);
- папки с моделями для  (откуда подгружаются файлы анимаций, например models/humans/...);
- дополнительные .mdl с анимациями для конкретной модели (привязка запоминается).
В окне виден список подключённых моделей: какие найдены и где лежат, какие нет.

Окно
----
Системный заголовок убран: название, кнопки окна и перетаскивание - в верхней панели (двойной клик -
развернуть, края и углы - размер, Aero Snap работает).
Структура
---------
Shell\Native.cs     - Win32, перехват горячих клавиш
Shell\Theme.cs      - палитра, шрифты, общие контролы (единый стиль)
Shell\Dialogs.cs    - диалоги, настройки
Shell\Pane.cs       - базовые типы содержимого областей
Shell\Explorer.cs   - проводник
Shell\Views.cs      - встроенные программы и "Главная"
Shell\Workspace.cs  - области, разделение, вкладки
Shell\Stages.cs     - этапы работы
Shell\Notify.cs     - уведомления
Shell\Vtf.cs, Mdl.cs, Anim.cs, Phy.cs, Gl.cs - форматы Source и OpenGL
Shell\ModelView.cs, Bindings.cs - просмотр моделей
Shell\SourceSDK.cs  - главное окно
Shell\build.bat     - сборка в SourceSDK.exe
